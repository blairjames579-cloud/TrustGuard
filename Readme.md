# TrustGuard 🛡️
A local-first, multi-tier threat blocker for Chrome. Protects against Phishing, Malware, Lookalike scams, Low-Trust sources, and unencrypted HTTP traffic.

## Installation
1. Download this repository as a `.zip` file and extract it to a folder on your computer.
2. Open Chrome and navigate to `chrome://extensions`.
3. Toggle **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select your extracted `TrustGuard` folder.
